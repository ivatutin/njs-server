# Coordination outbox (`njs-server`)

Канал связи с координатором (`c:\vim\prj\video-service`). Существует на случай, если папка координации
из задачи **не открывается** (рабочая папка ограничена `C:\WORK\v1m`) — как это было у фронт-сессии.

- `questions/` — **вопросы и отчёты** сессии. Один файл = одно сообщение. Шапка:
  `Кому / От кого / Дата / Статус` (`вопрос` → `отвечено` → `принято`).
- `replies/` — **ответы координатора**: он кладёт их сюда сам, копия остаётся в архиве координации.

Правило: **отчёт = файл, а не сообщение коммита.** Коммитить файлы отсюда не обязательно (можно — это не ошибка).

Переписка из `c:\vim\prj\video-service\docs\auth\sessions\njs-server\` остаётся канонической: сюда попадают
копии, чтобы канал работал при любом ограничении рабочей папки.
